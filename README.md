# OmniBoard

**Organize projects. Track tasks. See progress.**

OmniBoard is a planned project management board for organizing work and tracking tasks by status. The goal is to give users a clear view of what needs to be done, what is in progress, and what is complete.

> **Status: Planning.** This README describes the proposed first version. Features listed below are planned and are not yet confirmed as implemented.

## Overview

OmniBoard aims to bring projects and their tasks into a simple visual workspace. Users will be able to break projects into manageable tasks, update task details, and move work through a clear workflow.

The proposed default workflow is **To Do → In Progress → Done**.
